# PT-LOCALIZATION

Collection of Portuguese strings that can be used to localize the game on PC (since it lacks an official Portuguese translation)

## Ready to use translation

You can download a ready to use translation [HERE](https://b2.wtf/language-library#language-rqKQjgqa)

## Vanilla strings

If you only want to see strings dumped directly from XBOX (skipping additional translations), visit [this branch](https://github.com/B2ORG/PT-LOCALIZATION/tree/vanilla-strings/)
